# e-absensi-sekolah-laravel
Sistem Informasi Absensi Siswa berbasis web yang dikembangkan menggunakan Laravel dan MySQL. Aplikasi ini menyediakan fitur login, manajemen data siswa, absensi harian, validasi absensi ganda, pencarian data, rekap bulanan, dashboard statistik, visualisasi grafik kehadiran, serta export laporan absensi ke PDF.
