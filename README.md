# E-Absensi Sekolah Laravel

Sistem Informasi Absensi Siswa berbasis web yang dikembangkan menggunakan Laravel dan MySQL untuk membantu pengelolaan data kehadiran siswa secara digital.

## Fitur Utama

* Login dan Logout
* Manajemen Data Siswa (CRUD)
* Pencatatan Absensi Harian
* Validasi Absensi Ganda
* Filter Absensi Berdasarkan Tanggal
* Rekap Absensi Bulanan
* Dashboard Statistik Kehadiran
* Grafik Absensi
* Export Laporan PDF

## Teknologi

* Laravel 10
* PHP 8
* MySQL
* Bootstrap 5
* Chart.js
* DomPDF
